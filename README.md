# Personal World Game

这是一个用 Vite + React 实现的个人小世界互动网站。页面以游戏化世界地图为入口，访客从欢迎页进入地图，再点击不同建筑进入对应房间详情。

## 文档入口

- [项目实现说明](docs/项目实现说明.md)：说明网站架构、页面流程、组件职责、数据配置、素材与样式实现。
- [变更记录](docs/变更记录.md)：以后所有新增、删除、修改、查询都必须记录在这里。

## 本地运行

```bash
npm install
npm run dev
```

开发服务由 Vite 启动，默认会优先使用 `http://localhost:5173/`。如果端口已被占用，Vite 会自动切到下一个可用端口。

## 构建

```bash
npm run build
```

构建产物输出到 `dist/`。

## 变更规范

每次改动完成后，都要同步更新 [docs/变更记录.md](docs/变更记录.md)。记录必须写清楚：

- 变更日期
- 变更类型：新增、删除、修改、查询
- 涉及文件
- 变更内容
- 验证方式
- 后续注意事项

如果只是查询现状，也要记录查询结论，避免后续重复排查。
