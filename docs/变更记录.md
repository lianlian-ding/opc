# 变更记录

本文件用于记录项目后续所有新增、删除、修改、查询。任何代码、素材、配置、文档层面的变更，都必须在这里补充记录。

## 记录规范

每条记录必须包含：

- 日期
- 类型：新增、删除、修改、查询
- 涉及文件
- 变更内容
- 验证方式
- 后续注意事项

推荐格式：

```md
## YYYY-MM-DD - 类型 - 简短标题

- 涉及文件：
  - `path/to/file`
- 变更内容：
  - 写清楚本次具体做了什么。
- 验证方式：
  - 写清楚跑了什么命令，或检查了哪个页面。
- 后续注意事项：
  - 没有则写“无”。
```
